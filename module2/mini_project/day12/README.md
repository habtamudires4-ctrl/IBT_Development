# Birr Watch | Live ETB Exchange Rate Tracker

A responsive, client-side currency converter and watchlist app built with **Vanilla JavaScript** and **CSS3**. It fetches real-time Ethiopian Birr (ETB) exchange rates using the Open Exchange Rates API, supports dynamic recalculations, and persists your watchlist via local storage[cite: 1, 3].

---

## ✨ Features

* **Real-time API Fetching**: Retrieves live ETB rates directly from the Exchange Rate API[cite: 1].
* **Instant Calculation**: Dynamically updates conversions as you type or select currencies[cite: 1].
* **Saved Watchlist**: Pin key currencies to monitor multiple conversion targets at once[cite: 1].
* **Local Storage Sync**: Preserves your selected currency and saved watchlist across browser refreshes[cite: 1].
* **Responsive Layout**: Designed for seamless use across mobile, tablet, and desktop viewports[cite: 4].

---
