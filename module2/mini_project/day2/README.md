# Day 12 Mini-Project: Habesha Eatery Mini-Site

A lightweight, fully accessible two-page mini-site built for **Habesha Eatery** located in Bole, Addis Ababa.

---

## ⚡ How to Open and Run

1. Open any file (`index.html`, `contact.html`, or `exercises.html`) directly in Google Chrome, Firefox, or Edge browser.
2. Navigate between pages using the `<nav>` bar links at the top.

---

## ♿ Accessibility Features Implemented

* **Keyboard Operability**: Every form input, link, and button receives standard focus styling and is fully operable via <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd>, and <kbd>Enter</kbd>.
* **Explicit Labels**: Every single `<input>`, `<select>`, and `<textarea>` is directly linked to an explicit `<label>` via matching `id` and `for` attributes.
* **Accessible Tables**: Built with semantic `<caption>`, `<thead>`, `<tbody>`, and explicit `scope="col"` or `scope="row"` headers.
* **Semantic Landmarks**: Formatted using proper standard tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<h1>`, `<h2>`).
* **Informative Media**: `<img>` tags feature meaningful `alt` attributes describing image context, and `<iframe>` embeds feature explicit `title` attributes.
* **W3C Validated**: Passed through the W3C Markup Validation Service with zero errors or warnings.
